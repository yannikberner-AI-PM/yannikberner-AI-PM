## Current public build

I am developing a reproducible evaluation prototype for three information-secure LLM team architectures. Each architecture uses local models and keeps company data inside the user's or company's environment and under their control. The evaluation will compare answer quality, reliability, latency, resource use, and operational trade-offs.

The implementation and measurements will be published only after the prototype runs reproducibly. Synthetic inputs and AI-assisted implementation will be labelled.

## How I work

- Start with the user problem and the decision the product must improve.
- Separate deterministic product logic from probabilistic AI behaviour.
- Make quality, latency, cost, privacy, and operational risk explicit.
- Use tests, evaluation cases, and observable acceptance criteria.
- Keep humans responsible for decisions that need judgment or accountability.
